# OptaFX

**OptaFX** is an automated trading platform for Deriv users.

> **Your ultimate automated trading and trusted Deriv third party website.**

## About

OptaFX is being developed as a modern, mobile-first trading workspace with a navy-blue interface. The application is built around automated strategy execution, live market data, bot management, account connectivity, trade monitoring and risk controls.

## Core platform

- Automated trading strategies and bots
- Bot creation, configuration and monitoring
- Start, pause, resume and stop controls
- Live market data and trading updates
- Position and trade-history monitoring
- Strategy testing and performance analysis
- Risk and execution controls
- Secure Deriv account authentication
- Responsive mobile and desktop interface

## Branding

- **Application:** OptaFX
- **Domain:** `optafx.site`
- **Theme:** Navy blue / dark trading interface
- **Tagline:** Your ultimate automated trading and trusted Deriv third party website

## Technology

OptaFX uses React, TypeScript, Vite, SCSS, Ant Design and real-time web communication components. The project retains the useful trading automation architecture of its upstream foundation while replacing upstream branding and application-specific presentation with OptaFX branding.

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Important

Never commit private API tokens, OAuth secrets or account credentials. Production credentials should be supplied through environment variables in the deployment environment.

## Status

OptaFX is under active development. Trading functionality should be tested on a demo account before any live use.
